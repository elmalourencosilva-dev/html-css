Imagens

Para adicionar imagens, você precisa do link da imagem. Depois é só colocar o link dentro do atributo src da tag <img> e pronto! A imagem vai aparecer na tela.

Mudar o Favicon

Para mudar o favicon, você precisa criar um arquivo .ico e colocá-lo na pasta do projeto. Depois, adicione a tag <link> rel="shortcut icon" href="imagem/favicon.ico" type="image/x-icon" no cabeçalho do documento, apontando para o arquivo .ico.

Para deixar um texto em negrito, você pode usar a tag <b> ou <strong>. A tag <b> é usada para dar destaque ao texto, enquanto a tag <strong> é usada para indicar que o texto é importante.

Colocar Abreviação

Para colocar uma abreviação, você pode usar a tag <abbr>. A tag <abbr> é usada para indicar que o texto é uma abreviação e deve ser lido como tal.

Colocar Citação

Colocar Tabela

Para criar uma tabela, você pode usar a tag <table>, a tag <tr> (table row), a tag <th> (table header) e a tag <td> (table data). A tag <table> é usada para criar a tabela, a tag <tr> é usada para criar cada linha da tabela, a tag <th> é usada para criar o cabeçalho da tabela e a tag <td> é usada para criar cada célula da tabela.
